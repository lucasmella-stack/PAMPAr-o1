# Contributing

Spanish version: [CONTRIBUTING.es.md](CONTRIBUTING.es.md)

## Quick start
- Fork the repo
- Create a feature branch
- Add tests where reasonable
- Open a PR

## Code style
- Keep changes minimal and focused.
- Do not translate code; documentation can be bilingual.

## Licensing
