# Contribuir

English version: [CONTRIBUTING.md](CONTRIBUTING.md)

## Inicio rápido
- Fork del repo
- Crear una rama
- Agregar tests cuando sea razonable
- Abrir un PR

## Estilo
- Mantener cambios mínimos y focalizados.
- No traducir código; la documentación sí puede ser bilingüe.

## Licencia
Al contribuir, aceptás que tus contribuciones se licencien bajo **AGPL-3.0-or-later**.
