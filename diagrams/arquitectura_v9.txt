# PampaR v9 - Territorial Architecture

## One-Line Definition

> **"PampaR is an artificial brain where the thalamus orchestrates tokens toward specialized territories (Expressive, Contextual, Formal, Structural) that collaborate via bidirectional frontiers, combining explicit rules (LLAVES 70%) with learned attention (30%) to generate language."**

## Tálamo Routing

```
              INPUT: x (embeddings), token_ids
                          │
                          ▼
    ┌─────────────────────────────────────────┐
    │                TÁLAMO                   │
    │                                         │
    │   LLAVES (70%)         ATTENTION (30%)  │
    │   ────────────         ───────────────  │
    │   "el" → lenguaje      Query(x) →       │
    │   "2"  → matemat       Softmax →        │
    │   "si" → lógica        learned weights  │
    │                                         │
    │            ↓ combine ↓                  │
    │                                         │
    │   Module weights @ aggregation matrix   │
    │            = Territory weights          │
    │                                         │
    └─────────────────────────────────────────┘
                          │
                          ▼
        {expresivo: 0.2, contextual: 0.1,
         formal: 0.1, estructural: 0.6}
```

## Processing Example

```
Token: "El resultado de 2+2 es cuatro"

Tálamo activations:
├── "El"       → Expresivo (0.8)
├── "resultado"→ Expresivo + Contextual
├── "2+2"      → Estructural (0.9) ⚡
│               └── Frontier Expresivo↔Estructural ACTIVE
├── "es"       → Expresivo
└── "cuatro"   → Expresivo + Estructural
                └── Frontier ACTIVE

Active frontiers: 2/6 = 66% computation saved
```
