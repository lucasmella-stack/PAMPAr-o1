                                    JUSTIFICACIÓN NEUROLÓGICA
═══════════════════════════════════════════════════════════════════════════════════════════════════

   LENGUAJE ↔ CONTEXTO (0.8 bidireccional)
   ─────────────────────────────────────────
   El lenguaje depende fuertemente del contexto para:
   • Resolver pronombres (él, ella, esto)
   • Mantener coherencia temporal
   • Interpretar significados ambiguos
   
   En el cerebro: Área de Broca ↔ Corteza prefrontal


   LÓGICA ↔ MATEMÁTICAS (0.7 bidireccional)
   ─────────────────────────────────────────
   El razonamiento formal usa estructuras similares:
   • Operaciones tienen estructura lógica
   • Lógica formal usa símbolos matemáticos
   • Ambos requieren pensamiento secuencial
   
   En el cerebro: Corteza parietal ↔ Prefrontal


   LENGUAJE → CREATIVIDAD (0.6)
   ─────────────────────────────
   La creatividad lingüística surge del lenguaje:
   • Metáforas combinan conceptos
   • Neologismos crean palabras nuevas
   • Poesía juega con estructuras
   
   En el cerebro: Temporal ↔ Prefrontal derecho


   PATRONES → MATEMÁTICAS (0.6)
   ─────────────────────────────
   Los patrones son la base de las matemáticas:
   • Secuencias numéricas
   • Regularidades
   • Predicción de siguientes elementos
   
   En el cerebro: Parietal inferior


   CREATIVIDAD → LENGUAJE (0.7)
   ─────────────────────────────
   Las ideas creativas se expresan en lenguaje:
   • Narrativa
   • Descripciones originales
   • Expresión de conceptos nuevos

                                    FLUJO DE SEÑALES
═══════════════════════════════════════════════════════════════════════════════════════════════════

   Ejemplo: "2 + 2 = 4, entonces si sumamos 2 más..."

   1. MATEMÁTICAS procesa "2 + 2 = 4"
      │
      └──0.7──► LÓGICA recibe señal
                │
                └──"entonces" activa LÓGICA más
                   │
                   └──0.6──► PATRONES detecta repetición de "2"
                             │
                             └──0.6──► MATEMÁTICAS refuerza
                                       (sinapsis bidireccional)

   Resultado: El módulo de MATEMÁTICAS tiene refuerzo extra
              por la comunicación sináptica circular


═══════════════════════════════════════════════════════════════════════════════════════════════════
                                    TIPOS DE SINAPSIS
═══════════════════════════════════════════════════════════════════════════════════════════════════

   ┌──────────────┬─────────────────────────────────────────────────────────────────────────────┐
   │ TIPO         │ DESCRIPCIÓN                                                                 │
   ├──────────────┼─────────────────────────────────────────────────────────────────────────────┤
   │ EXCITATORIA  │ Aumenta la activación del módulo destino                                   │
   │              │ señal_transmitida = señal × peso                                           │
   │              │ Uso: Cuando origen y destino deben cooperar                                │
   ├──────────────┼─────────────────────────────────────────────────────────────────────────────┤
   │ INHIBITORIA  │ Reduce la activación del módulo destino                                    │
   │              │ señal_transmitida = -señal × peso                                          │
   │              │ Uso: Cuando uno debe dominar sobre otro                                    │
   │              │ (No usado actualmente, reservado para futuro)                              │
   ├──────────────┼─────────────────────────────────────────────────────────────────────────────┤
   │ MODULADORA   │ Ajusta sutilmente sin excitar/inhibir                                      │
   │              │ señal_transmitida = señal × peso × 0.5                                     │
   │              │ Uso: Influencia suave, contexto de fondo                                   │
   │              │ Ejemplo: CREATIVIDAD → PATRONES (inspiración sutil)                        │
   └──────────────┴─────────────────────────────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════════════════════════════════════════════════
                                    IMPLEMENTACIÓN
═══════════════════════════════════════════════════════════════════════════════════════════════════

   class Sinapsis(nn.Module):
       
       # Cada conexión tiene:
       # 1. Regla sináptica (origen, destino, tipo, peso)
       # 2. Transformación lineal pequeña (dim → dim)
       
       def transmitir(origen, destino, señal):
           regla = self.reglas[(origen, destino)]
           
           if not regla.evaluar(contexto):
               return None  # No transmitir
           
           señal_transformada = self.transformaciones[f"{origen}_a_{destino}"](señal)
           
           if regla.tipo == EXCITATORIA:
               return señal_transformada * regla.peso
           elif regla.tipo == INHIBITORIA:
               return -señal_transformada * regla.peso
           else:  # MODULADORA
               return señal_transformada * regla.peso * 0.5
